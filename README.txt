Word Quest · Grade 7 Semester 1 · v1.4 mobile layout update

WORD QUEST – GRADE 7 (SHANGHAI FIVE-FOUR SYSTEM, 2024) – SEMESTER ONE

Site entry: index.html
Units: unit1.html, unit2.html, unit3.html, unit4.html, unit5.html, unit6.html
Required shared assets: quest.css, quest.js, content.js

Deploy: Upload the ZIP as a static site to Cloudflare Pages or Netlify,
keeping all eight files at the root. Use the generated HTTPS URL on iPhone Safari.

Content:
- Unit 1: 23 missions (preserved from Word Quest v1.3.2), 43 textbook entries.
- Unit 2: 17 missions, 48 textbook entries (opposites, word families).
- Unit 3: 17 missions, 56 textbook entries (occupational suffixes).
- Unit 4: 17 missions, 40 textbook entries (semantic networks).
- Unit 5: 17 missions, 42 textbook entries (prefixes).
- Unit 6: 18 missions, 36 textbook entries (dictionary skills).
- Grand total: 109 missions, 265 textbook vocabulary / expression entries.

Game content is original. Unit vocabulary transcribed from the 2024 textbook,
pp. 140–144, and checked against the textbook's Word Study sections 125–128.

Progress is stored locally, per browser and per unit. The previous Unit 1
storage key is deliberately retained, so saved browser progress survives
when the game is updated at the same URL origin. If the website changes
hostnames/domains or local storage is cleared, progress does not transfer.

Chinese assistance: ON shows translations for mission, question, clues and
explanations; when OFF each segment can be translated on demand. Choices
remain in English. All word-study explanations are visible after solving—
there is no Explore More click.

This game does not make live API requests to Etymonline, and is not officially
affiliated with the textbook publisher. Some content uses explicit word
families and semantic connections rather than verified etymological origins.
